초록
시계열 파운데이션 모델의 미세조정이 Zero-Shot 예측보다 유리해지는 학습 데이터 규모는 모델과 데이터에 따라 달라질 수 있다. 본 연구는 TTM-R3와 MOIRAI 1.1-R-small을 대상으로 제한된 optimizer-step 예산 아래에서 학습 윈도 풀의 크기에 따른 예측 오차 변화를 분석한다. ETTh1, ETTh2, ETTm1, ETTm2, Tetouan의 다섯 데이터 변형에 시간순 60/20/20 분할을 적용하고, context 512, horizon 96, 세 seed를 고정하였다. 학습 후보 윈도의 0.5%부터 100%까지 중첩 시간층화 표본을 사용하며, Zero-Shot을 포함한 총 270개 조건을 동일 test origins에서 평가하였다. 주 지표는 train 표준편차로 정규화한 채널 평균 MAE이다. 100% 후보 풀에서 평균 상대 오차 감소율은 TTM의 경우 0.31–5.38%, MOIRAI의 경우 0.93–51.17%였다. 평균 오차 기준에서는 모든 모델–데이터 조합에서 지속 개선 구간이 관측되었으나, 세 seed 모두의 지속 개선을 요구하면 TTM·ETTm1은 관측 범위 내 기준을 충족하지 못했다. 상대 개선 폭이 큰 모델이 반드시 더 작은 절대 오차를 보이는 것은 아니었다. 이 결과는 두 고정 모델과 다섯 데이터 변형에 대한 계산 예산 조건부 사례이며, 연속적인 전환 임계점, 수렴 성능 또는 데이터 특성의 인과 효과를 확정하지 않는다.

Abstract
Fine-tuning a time-series foundation model does not necessarily improve forecasting equally across models and datasets. We examine zero-shot to few-shot crossover under a bounded optimizer-step budget using TTM-R3 and MOIRAI 1.1-R-small. Five dataset variants—ETTh1, ETTh2, ETTm1, ETTm2, and Tetouan—are evaluated with chronological 60/20/20 splits, a context length of 512, a horizon of 96, and three seeds. Nested temporally stratified sampling selects training-window pools from 0.5% to 100%. The resulting 270 conditions, including zero-shot baselines, share identical test origins within each dataset. The primary metric is channel-macro MAE normalized by training-set standard deviations. At the 100% pool endpoint, mean paired relative error reductions range from 0.31% to 5.38% for TTM and from 0.93% to 51.17% for MOIRAI. Mean sustained improvement is observed for every model–dataset pair, but the all-three-seed sustained criterion is not met by TTM on ETTm1. Larger relative gains do not necessarily imply lower absolute forecast error. These findings characterize grid-based, budget-conditional behavior rather than continuous thresholds, convergence performance, or causal effects of dataset characteristics.

핵심어
시계열 파운데이션 모델; Zero-Shot; Few-Shot Fine-Tuning; 전환 구간; 중첩 표본; 제한된 계산 예산

1. 서론
다수의 시계열에서 사전학습한 파운데이션 모델은 대상 데이터에서 파라미터를 갱신하지 않는 Zero-Shot 예측과 제한된 대상 학습 데이터를 이용한 Fine-Tuning을 지원한다[1,2]. 그러나 미세조정으로 얻는 이득은 사전학습 모델의 출발 성능, 대상 시계열의 구조, 표본 선택, 학습 예산에 함께 영향을 받는다. 따라서 단일 학습 비율의 성능을 비교하는 것만으로는 어느 범위부터 미세조정이 유리해지는지 설명하기 어렵다.

본 연구의 질문은 고정된 모델과 최대 optimizer-step 규칙 아래에서 학습 윈도 풀의 크기가 증가할 때 Zero-Shot 대비 개선이 처음 나타나고 이후 관측 비율에서 유지되는 구간이 어디인가이다. 이를 두 모델의 절대 순위와 구분하여 분석한다. 동일 표본·분할·평가 규칙을 적용하되 모델 고유의 학습 목적함수와 예측 방식을 유지한다. 본 연구의 기여는 (1) 중첩된 시간층화 표본과 paired seed 평가에 기반한 전환 구간 산출, (2) 평균 개선과 세 seed 모두의 지속 개선을 구분한 결과 제시, (3) 선택 풀 크기와 실제 학습 노출량을 구분한 예산 조건부 해석이다. 연구는 다섯 데이터 변형에 대한 탐색적 사례 분석으로 한정한다.

2. 관련 연구
TTM은 사전학습된 mixer 계열 시계열 모델로 Zero-Shot 및 Few-Shot 예측을 다룬다[1]. 본 실험에는 기본 논문의 가중치와 동일하다고 가정하지 않고, 별도로 고정한 TTM-R3 checkpoint를 사용하였다[6,8]. MOIRAI는 다양한 시계열을 처리하는 범용 예측 모델 연구로 제시되었다[2]. 본 실험은 해당 계열의 MOIRAI 1.1-R-small과 고정 Uni2TS 구현을 사용한다[7,9]. 원 논문과 후속 checkpoint의 구분을 유지한다.

TSFM-Bench는 시계열 파운데이션 모델 평가와 관련된 공개 벤치마킹 저장소이다[5]. 본 연구는 이를 관련 연구로 인용하되 코드·셸 구조·모델 버전·하이퍼파라미터를 구현 기준으로 복제하지 않았다. 따라서 TSFM-Bench 결과의 재현, 동일 조건 직접 비교 또는 그보다 우수하다는 주장을 하지 않는다. ETT 데이터는 Informer 연구 및 공식 데이터 저장소를, Tetouan은 UCI 공개 데이터 출처를 따른다[3,4,10].

3. 실험 방법
3.1 데이터와 분할
ETTh1·ETTh2는 시간 단위, ETTm1·ETTm2는 15분 단위, Tetouan은 10분 단위 관측이다. ETT 변형은 각 7개 채널을 사용한다. Tetouan은 기상 5개 변수와 3개 구역 전력 사용량을 포함하는 8개 수치 채널 모두를 예측 대상으로 사용한다. 모든 데이터는 시간순으로 train 60%, validation 20%, test 20%로 분할하며 정수 경계는 실제 manifest를 따른다. 확보·준비된 본 분석의 다섯 데이터에는 결측 셀과 중복 timestamp가 없었다. 각 데이터의 fingerprint, 행 수, 채널 순서와 분할 크기는 표 1 및 부록 자료에 제공한다.

두 ETTh/ETTm 쌍은 같은 변압기의 시간 해상도 변형이므로 독립된 네 원천 데이터로 취급하지 않는다. 분석상 다섯 변형은 두 ETT 변압기와 Tetouan의 세 출처군에 해당한다. context와 horizon은 각각 512와 96개 시점으로 고정되지만 horizon의 실제 길이는 ETTh에서 96시간, ETTm에서 24시간, Tetouan에서 16시간이다.

3.2 학습 표본과 계산 예산
context와 target이 모두 train 안에 있는 stride-1 후보 윈도의 개수를 N이라 하자. 비율 r에 대하여 k=max(1, floor(rN))개를 정확히 선택하였다. r은 0.005, 0.01, 0.02, 0.05, 0.1, 0.2, 0.5, 1.0이다. 후보 시간을 연속 층으로 나누고 seed에 따라 층 내부 순서를 섞은 뒤 층을 교차 방문하는 하나의 순서를 만든다. 각 비율은 그 순서의 prefix이므로 동일 seed에서 작은 표본이 큰 표본에 포함된다. 모델 간에도 같은 index manifest를 사용한다. 채널은 비율별로 삭제하지 않는다.

두 모델 모두 full-parameter fine-tuning, batch size 1, gradient accumulation 1, FP32, 최대 1,000 optimizer steps를 적용한다. 매 100 step에 고정된 64개 validation origins를 평가하고, 주 validation 지표가 세 번 연속 개선되지 않으면 조기 종료한다. 실제 종료 step과 가장 좋은 validation step은 구분하여 기록한다. optimizer는 AdamW이며 TTM의 학습률/weight decay는 10^-4/0.01, MOIRAI는 5×10^-6/0.1이다. scheduler와 gradient clipping은 사용하지 않는다. 이 값들은 실행 설정이며 test 결과를 보고 재조정하지 않는다. 모든 비율을 1,000 step까지 반드시 학습한 것이 아니며 모델 간 동일 FLOPs·시간·epoch를 보장하지 않는다.

3.3 모델과 예측
TTM은 고정 R3의 512-96-dec-512-r3 checkpoint를 사용한다. H96에서는 외부 context zero-padding이나 더 긴 horizon의 crop이 필요하지 않다. 공식 decomposed prediction 경로의 출력과 loss를 사용한다. MOIRAI는 1.1-R-small, patch size 64, 공식 MoiraiFinetune 및 PackedNLLLoss를 사용한다. 두 모델의 학습 objective를 동일 MSE로 바꾸지 않았다. TTM은 내부 channel-independent/shared-weight 구조이고 MOIRAI는 joint-target 구조이므로, 다변량 입력이 같다는 사실을 동일한 채널 상호작용 구조로 해석하지 않는다.

외부 StandardScaler는 사용하지 않고 각 모델의 native scaling을 유지한다. 출력 및 raw MAE/MSE는 원 단위로 계산한다. TTM은 공식 prediction_outputs를 point forecast로, MOIRAI는 100개 확률 표본에 대한 torch sample median을 사용한다. 짝수 표본 수에서 이 구현은 가운데 두 값의 평균이 아니라 하위 중앙 순서통계량이다. Zero-Shot과 Fine-Tuning에 동일한 scaling 및 point forecast 규칙을 적용한다. 정확한 model revision, 공식 코드 commit, 패키지 버전과 실행 환경은 재현 자료에 별도로 제공한다.

3.4 평가와 전환 구간
각 데이터의 모든 조건은 동일한 stride-1 rolling-origin test windows를 사용한다. target은 test 안에만 위치하며, 이후 origin의 context에는 그때까지 관측된 실제 test 값이 들어갈 수 있다. 이는 모델 파라미터, scaler, checkpoint 또는 설정을 test로 갱신하는 것과 구분한다. validation/test target을 train 입력 생성이나 학습에 사용하지 않는다.

주 지표는 채널별 MAE를 해당 채널의 train population standard deviation으로 나눈 뒤 채널 간 동일 가중 평균한 normalized MAE이다. 이는 모델 외부 입력 정규화나 MASE가 아니다. normalized MSE와 원 단위 MAE/MSE는 보조 지표로 제시한다. 같은 model–dataset–seed의 Zero-Shot 오차 E(0,s)와 Fine-Tuning 오차 E(r,s)를 대응시키고, 상대 개선은 I(r,s)=[E(0,s)-E(r,s)]/E(0,s)로 정의한다. 상대 개선의 평균은 seed별 비율을 먼저 계산한 뒤 평균하며, 평균 오차 간 비율로 대체하지 않는다.

평균 지속 개선은 평균 paired 오차 차이가 양수이고 모든 이후 관측 비율에서도 양수인 첫 격자 비율로 정의한다. 보수적 동반 기준은 세 seed 각각에서 이 조건을 만족하도록 요구한다. 표의 (r_prev, r]는 해당 격자의 위치를 표현하며 이 구간 내 연속적인 함수의 근이나 단조성을 검증한 신뢰구간이 아니다. 가장 작은 비율인 0.5%에서 기준을 충족하면 그보다 아래의 전환 위치는 측정하지 못한다. 기준 미충족을 미실행이나 결과 누락으로 해석하지 않는다. 세 seed의 범위는 기술적 변동 범위이며 통계적 유의성이나 95% 신뢰구간을 뜻하지 않는다.

4. 결과
4.1 데이터별 전환과 endpoint
두 모델×5개 데이터 변형×3개 seed×9개 비율(Zero-Shot 포함)의 270조건에 대해 completed final-test 기록을 확인하였다. 표 2의 endpoint는 test 결과로 가장 좋은 비율을 고른 것이 아니라 공통 격자의 끝인 100% 후보 풀을 요약한 것이다. 각 비율 전체 결과는 그림 1과 부록 수치표에 제공한다.

4.2 상대 개선과 절대 오차의 구분
MOIRAI는 ETTm1·ETTm2·Tetouan에서 상대적으로 큰 개선 폭을 보였다. 그러나 100% pool의 평균 normalized MAE는 다섯 데이터 변형 모두에서 TTM이 더 낮았다. 따라서 큰 미세조정 이득을 곧바로 더 우수한 최종 예측 성능으로 해석해서는 안 된다. 본 연구의 중심 질문은 모델 내부의 Zero-Shot–Few-Shot 변화이며, 두 모델의 절대 오차는 이를 해석하는 보조 정보이다.

TTM·ETTm1은 평균 지속 개선 기준을 충족하지만 세 seed 모두의 지속 개선 기준은 충족하지 않았다. 100% pool에서 seed 31415의 상대 개선은 약 -0.0833%였다. 일부 중간 비율에서 세 seed가 모두 개선되더라도 이후 비율에서 다시 기준을 위반하면 지속 개선으로 분류하지 않는다. 이는 27개 해당 조건이 모두 실행된 상태에서 관측한 비단조적 변동이다.

4.3 학습 노출과 지표 민감도
선택 풀의 비율과 실제 방문한 윈도 수는 다르다. 100% pool 조건에서 종료 시점까지 방문한 고유 윈도는 전체 후보의 약 0.97–10.16%였으며, 이는 best checkpoint 시점의 노출량과도 구분된다. 특히 예산 끝에서 가장 좋은 validation 값을 얻은 조건은 더 긴 학습으로 개선될 여지가 남아 있으므로 수렴했다고 판단하지 않는다.

보조 normalized MSE에 세 seed 모두의 지속 개선 기준을 적용하면 MOIRAI·ETTh1과 ETTh2의 구간은 각각 (10%,20%], (5%,10%]로 나타나 normalized MAE 결과와 달랐다. 채널별 결과, seed 하나씩 제외한 결과, 1%/2% 상대 개선 마진, 출처군 단위 요약은 부록에 제공한다. 이들은 결과를 본 뒤 계산한 기술적 민감도 분석이며 주 지표나 학습 설정을 교체하기 위한 분석이 아니다.

5. 논의 및 한계
같은 학습 규칙에서도 모델과 데이터 변형에 따라 개선 폭과 seed 안정성이 달랐다. train-only lag-1 상관과 선형 추세 요약을 함께 제공하지만, 다섯 변형과 세 출처군만으로 특정 특성이 전환을 결정한다는 인과 주장이나 일반화 회귀를 수행하지 않는다. 계절성은 이번 descriptor 집합에서 추정하지 않았다. 관측 해상도와 horizon의 물리적 길이, 모델의 출발 오차, 목적함수, 실제 학습 노출량이 함께 영향을 줄 수 있다.

첫째, 동일 최대 optimizer-step 규칙은 수렴 비교나 동등한 연산량 비교가 아니다. 둘째, H96만 분석하므로 장기 horizon으로 일반화할 수 없다. 셋째, seed는 세 개이며 MOIRAI의 학습 및 표본 생성 seed 효과를 분리하지 않았다. rolling windows는 서로 겹치므로 이를 독립 표본으로 간주한 bootstrap이나 검정은 하지 않았다. 시간 block 기반 불확실성과 동일 epoch 재학습은 수행하지 않았다. 넷째, 모델 사전학습 corpus와 평가 데이터의 중복을 독립적으로 감사하지 않았으므로 대상 학습·평가 누수 방지와 사전학습 오염 부재를 동일시하지 않는다. 다섯째, 실제 TTM 실행에 A100 40GB와 T4가 함께 사용되었으므로 시간·메모리를 통제된 모델 속도 경쟁으로 해석하지 않는다. 마지막으로, 다섯 데이터 변형·H96·두 모델이라는 최종 분석 범위는 결과가 이용 가능한 뒤 확정되었다. 원래 더 넓은 계획의 전체 완료나 사전등록 연구라고 주장하지 않는다.

6. 결론
본 연구는 두 고정된 시계열 파운데이션 모델에서 중첩 학습 윈도 풀과 제한된 optimizer-step 예산에 따른 Zero-Shot–Few-Shot 전환을 분석하였다. 평균 개선과 모든 seed에서의 지속 개선은 구분되어야 했으며, 미세조정 상대 이득과 절대 예측 성능 또한 일치하지 않았다. 결과는 데이터 특성에 따른 차이를 탐색할 출발점이지만, 전환점의 보편 법칙이나 수렴 성능을 제시하는 것은 아니다. 제공한 실행 식별자, 표본·test window hash, 모델 revision 및 수치표는 관측 결과와 해석 범위를 추적할 수 있게 한다.
