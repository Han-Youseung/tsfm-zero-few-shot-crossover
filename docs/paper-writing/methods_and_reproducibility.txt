3. 표본
r={0.005,0.01,0.02,0.05,0.1,0.2,0.5,1}; k=max(1,floor(rN)). r=0은 학습 없음.
동일 seed에서 master order를 하나 만들고 prefix k개를 선택하여 S_0.5% ⊆ ... ⊆ S_100%를 보장한다.
구현은 K=min(ceil(sqrt(N)),N)개의 연속 시간층, seed에 따른 층 내부 shuffle, bit-reversal 기반 층 순서 및 round별 순서 이동을 사용하여 층을 교차 방문한다. 학습 batch shuffle과 표본 선택은 별도 단계이다.
모델 간 동일 sampling manifest hash를 확인하였다. 실제 k/N과 요청 r은 floor 때문에 다를 수 있다. 표의 requested_rate는 분수 단위이며 0.005=0.5%, 0.5=50%이다.
100%는 후보 풀을 모두 허용한다는 뜻이지 모든 후보를 한 번 이상 학습했다는 뜻이 아니다. actual_unique_windows는 학습 종료까지 방문한 고유 윈도 수이다. best_validation_step에서의 노출 수를 직접 측정한 값으로 해석하지 않는다. 실제 구현의 equivalent_epochs와 average_window_exposures는 둘 다 누적 윈도 노출/선택 풀 크기이다. 실제 방문 고유 윈도만을 분모로 쓴 평균이 아님에 주의한다.

5. 수식 (편집 가능한 plain text / LaTeX notation)
채널 c의 train 평균 및 표준편차:
mu_c = (1/T_train) sum_{t in train} y_{t,c}
sigma_c = sqrt[(1/T_train) sum_{t in train} (y_{t,c}-mu_c)^2]
이는 ddof=0인 population std이다.

평가 원소 집합 Omega_c={(origin,lead): 해당 target이 평가 가능}, n_c=|Omega_c|일 때:
MAE_c = (1/n_c) sum_{(o,h) in Omega_c} |y_{o+h,c} - yhat_{o,h,c}|
MSE_c = (1/n_c) sum_{(o,h) in Omega_c} (y_{o+h,c} - yhat_{o,h,c})^2
NMAE = (1/C') sum_{c in eligible} MAE_c/sigma_c
NMSE = (1/C') sum_{c in eligible} MSE_c/sigma_c^2
eligible은 sigma_c>1e-8인 채널; 이번 5개 데이터에서 제외된 정규화 채널은 0개. raw MAE/MSE는 채널별 원 단위 결과도 제공하나 단위가 다른 채널의 raw macro 값을 주요 모델 비교 근거로 삼지 않는다. NMAE는 percentage error나 MASE가 아니다.

paired 오차 차이 D_{r,s}=E_{0,s}-E_{r,s}; 상대 개선 I_{r,s}=D_{r,s}/E_{0,s}.
mean D_r=(1/3)sum_s D_{r,s}; mean I_r=(1/3)sum_s I_{r,s}.
평균 지속 개선 격자 j*=min{j: 모든 k>=j에 대해 mean D_{r_k}>0}.
세 seed 모두 지속 개선 격자 j*=min{j: 모든 k>=j 및 모든 s에 대해 D_{r_k,s}>0}.
조건을 만족하는 j가 없으면 기준 미충족. 표시 구간은 (r_{j-1},r_j], j=1이면 아래 표시 경계는 0. 연속 함수의 근을 증명하지 않는다. 'first improvement'는 단 한 비율에서 처음 양수가 되는 별도 항목이므로 sustained와 혼동하지 않는다.

6. 추가 분석과 통계 경계
보조 지표 4종, 채널별 분석, seed 하나 제외, 1%/2% 상대 개선 마진, 출처군 단위 요약은 evidence/analysis.json에 있다. 모두 기존 metric 기록의 CPU 기술통계이며 test 예측을 새로 생성하지 않았다. 1%/2% 마진을 임상적·산업적 유의성 기준이라고 주장하지 않는다.
원소별 prediction/error array가 없으므로 현재 집계 JSON만으로 새로운 시간-block bootstrap을 수행하거나 valid CI를 만들 수 없다. seed 3개의 최소–최대는 CI가 아니다. 서로 겹친 rolling window를 독립 표본으로 bootstrap하지 않는다.
train descriptor는 인접 실제 관측의 Pearson lag-1 상관을 채널 평균하고, 각 채널 OLS 추세의 절대 기울기×(train_rows-1)/train_std를 채널 평균한 값이다. 둘 사이 특성과 crossover의 상관 유의성·인과·계절성 결과를 만들지 않는다.
